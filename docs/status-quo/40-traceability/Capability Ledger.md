## Set boundary

The 33 IDs above include implemented, partial, prototype, absent, and planned-only rows because traceability must account for the whole declared vocabulary. Equivalence implementation includes only current behavior at its recorded reachability. `PDF-00`, `UNDO-00`, and `CIRCLE-00` are negative/containment rows, while `SHELL-03` records a user-facing absence whose backend security counterpart remains implemented.

[[Feature-to-Code Matrix]] must contain the identical first-column set with no duplicates. Any capability added, removed, renamed, or reassigned requires the owning feature frontmatter, both ledgers, Atlas navigation, and validation proof to change together.
